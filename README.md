# 🎲 Proyecto "Simulador de Juego de estrategia con IA. El Parchís como caso de estudio".

Este proyecto tiene como objetivo emplear y analizar el desempeño de distintas técnicas de **Inteligencia Artificial** como heurísticas y aprendizaje automático en un entorno no determinista. Para ello, se implementa el clásico juego **Parchís** basado en la aleatoriedad de los dados, sobre el cual se llevará a cabo el estudio.

---

## 🎯 Objetivos principales del proyecto

- Implementar la lógica del juego Parchís.
- Permitir partidas entre jugadores humanos, cuya utilidad principal en el contexto del proyecto es recopilación de los datos para el entrenamiento del sistema.
- Desarrollar módulos de IA que permitan partidas contra la máquina o entre distintas IA, con el fin de analizar el rendimiento del sistema según el nivel de aprendizaje.
- Analizar el desempeño del sistema con el fin de mejorar los algoritmos.
  
---

## ⚙️ Tecnologías principales

- **Java 21**, **Spring Boot 3**, **Maven**
- **MySQL** (en local), **H2** (CI)
- **Redis** 
- **WebSocket** 
- **JGraphT**, **Commons Math**, **DeepLearning4J** 
- **SonarCloud** + **GitHub Actions**
